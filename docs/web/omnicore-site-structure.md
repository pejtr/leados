# OMNICORE Site Structure

## Verdict

OMNICORE should become the public technology layer for ONYX OS and the strategic infrastructure brand behind OPTIMATEO.

## Brand Architecture

- OPTIMATEO = implementation studio / sales brand
- OMNICORE = technology core / Agentic Intelligence Layer
- ONYX OS = client-facing operating layer
- Revenue Leakage Audit = first sellable entry product

## Recommended Website Structure

### /

Homepage for OMNICORE as an Agentic Intelligence Layer.

Sections:

1. Hero
2. Problem
3. What OMNICORE does
4. ONYX OS
5. Revenue Leakage Audit
6. Data Governance
7. Docs / BRD Pack
8. Call to Action

### /onyx-os

Product page for ONYX OS.

Purpose:

- explain the operating layer
- show pilot-first rollout
- connect to Source Data Harmonizer
- position ONYX OS as client-facing intelligence infrastructure

### /revenue-leakage-audit

First commercial offer.

Purpose:

- sell a 25k-75k CZK audit
- identify funnel leakage
- prepare implementation roadmap
- create cashflow before heavy product development

### /docs

Public or semi-public documentation section.

Recommended initial docs:

- BRD Pack v1
- Agentic Intelligence Layer
- Source Data Harmonizer
- Omnichannel Conversion Mapping
- World Monitor Data Governance

## Out of Scope

- Full SaaS dashboard launch
- Public claim of unverified API integrations
- Enterprise compliance claims before legal/data review
