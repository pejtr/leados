# Message Rules

Pravidla pro generování a QA oslovovacích zpráv. Porušení = zamítnutí návrhu v OMNICORE QA.

## Povolené

- Krátké představení (kdo jsme, co děláme).
- Ověřený relevantní kontext (veřejný signál s odkazem).
- Jasný, neagresivní důvod ke spojení.
- Jedna konkrétní hodnota nebo otázka, ne „tahák“.
- CTA: připojit se / krátká odpověď, ne „koupit teď“.
- Délka: connection request ≤ 300 znaků, zpráva ≤ 600 znaků.

## Zakázané formulace a vzorce

- „Viděl jsem, že jste v roce X udělali Y…“ (příliš osobní historie).
- Falešná chvála / předstírání osobního vztahu.
- Zneužití rodiny, bydliště nebo soukromých událostí.
- Tvrzení vydávaná za fakt bez `sourceEvidence` (např. „ztrácíte zákazníky“).
- Automaticky generovaný odstavec působící jako spam.
- Manipulativní „urgentní“ tlak.
- Konkrétní interní detaily z profilu, které působí jako sledování.

## Varianty (experimenty)

- **A** — krátké spojení bez nabídky.
- **B** — relevantní pozorování (veřejný signál).
- **C** — nabídka mini auditu.
- **D** — reakce na veřejný firemní signál.

Měříme: přijetí spojení, odpověď, pozitivní odpověď, schůzku, nabídku, placenou zakázku.
Neměříme: počet vyrobených zpráv, počet „prozkoumaných“ profilů.
